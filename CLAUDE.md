# Ernest-Performance

Ernest Performance — coaching / performance brand.

This repo follows the shared organisation convention in [`ORGANIZATION.md`](./ORGANIZATION.md):
one canonical name (`Ernest-Performance`) across the GitHub repo, the Chat
Project, and the Cowork Project. Keep Cowork chats inside the matching Cowork
Project.

## Workshop Pro

The staff-facing club-fitting/build app (Base44 "EP Workshop Pro"). Its
architecture — data model, brand-portal ingestion, quoting/invoicing via
Shopify, staged Klaviyo notifications, migration plan — is specified in
[`workshop-pro/ARCHITECTURE.md`](./workshop-pro/ARCHITECTURE.md). Read it
before changing the app; it is the source of truth for how pieces fit.

## Working files

Working files live under `project/`. This includes the weekly "Winner's Bag"
(WITB) Instagram carousel — a collab published with the Dialled In Pod. See
[`project/CLAUDE.md`](./project/CLAUDE.md) before touching the carousel build.
